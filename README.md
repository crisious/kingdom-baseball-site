# kingdom-baseball-site

KINGDOM NINE(天下九團) 웹 셸의 **정적 미리보기 배포물**입니다. 이 저장소에는 소스가 없습니다 — 소스는 비공개 `kingdom-baseball` 저장소에 있고, 그쪽의 GitHub Actions(`Deploy static site`)가 빌드 산출물만 `gh-pages` 브랜치로 밀어 넣습니다.

- 사이트: https://crisious.github.io/kingdom-baseball-site/
- 백엔드(API)가 없으므로 편성·경기·영입·구장 등 제품 흐름은 동작하지 않고 UI 셸만 확인할 수 있습니다.
- 선수 카드 아트·영상(성인/등급 세트)은 배포물에서 제외됩니다. 검색 엔진 색인은 `robots.txt`·`noindex` 로 막습니다.
- 직접 편집하지 마세요. 다음 배포가 `gh-pages` 를 덮어씁니다.
